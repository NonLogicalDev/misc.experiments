# Nonlogical's Personal Projects

A ragtag collection of projects I am working on but am not yet ready to fully release.

## Projects

- [cli.macctl](projects/cli.macctl)
  - A macOS command-line tool for brightness and sleep controls.

- [vscode.nonlogical.stacked-git](projects/vscode.nonlogical.stacked-git)
  - A VSCode extension for stacked git.
  - Provides just enough UI to observe and lightly tend to Git Patch Stacks.

- [misc.git-utils](projects/misc.git-utils)
  - A collection of utility scripts for working with git.
  - Mostly scripts for working with stacked branches.

- [tool.quick-interview-runner](projects/tool.quick-interview-runner)
  - An experimental tool for running interviews use bazel.
  - Uses new fancy bazel module system.

- [tool.qemu-tools](projects/tool.qemu-tools)
  - A tool for building QEMU images without going crazy.
  - This project is an answer to the question what if QEMU was made like Docker?

- [tool.promql-builder](projects/tool.promql-builder)
  - A tool for building complex PromQL queries without going crazy.
  - This project is basically the answer to the question what if PromQL was made like shell
  - Or what if PromQL was made like Flux?
  - Or what if PromQL was made for humans

- [tool.pam-ussh-rs](projects/tool.pam-ussh-rs)
  - An experimental attempt to rewrite Uber's open source ussh PAM module in Rust.
  - Queries ssh-agent for certs and uses certs to determine if a user is eligible for sudo.
