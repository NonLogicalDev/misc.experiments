# stacked-git in VSCode

This extension is a comprehensive integration of stacked git into the SCM function set of VSCode.

Supports:
* Viewing the stack at a glance
  * Including files under each patch
* Pushing multiple patches onto the stack
* Goto command implemented
* Viewing patches contents
* Viewing file contentes at any given patch
* Safely pulling from remote with merge detection via `stg pull -m`
