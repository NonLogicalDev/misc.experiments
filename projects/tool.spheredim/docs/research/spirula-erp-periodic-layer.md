# Experimental equirectangular raster seam patch

This disabled layer widens only equirectangular AABBs that cross the horizontal boundary, uses conservative tile and microtile culling for equirectangular renders, and selects the single horizontal period minimizing the 3DGS conic in forward and backward. It carries an explicit camera flag through 2D host and CUDA APIs. The 3DGUT path retains its existing positive closest-ray-depth test. The periodic flag is disabled for other camera models; their behavior still needs regression tests.

The source and committed CUDA header were generated with Slang 2026.2.1, official macOS arm64 archive SHA-256 `e837adf6a953e869917c9ce64b975609df8fbcf09079d2d5e96f5fc2c3e79636`, using upstream postprocessing. Regenerating the unchanged baseline with that macOS compiler differed from the committed header in one reordered pair construction; the layer uses the actual generated changed header. The C++ header and CUDA template instantiation generators were rerun and were stable on a second pass.

A targeted Apple M2 Pro Vulkan fixture passed 16 packed/unpacked 3DGS/3DGUT forward comparisons against periodic CPU references, including small, ordinary, tilted and wide shapes, plus 28 finite-difference gradient checks for the ordinary seam case. Its 192×120 pinhole controls had bit-identical alpha and no gradient difference beyond absolute 1e-5 plus relative 1e-4. The targeted fixture uses a partial shader registry and is not a full-trainer result. CUDA compilation and AMD execution remain untested. Do not enable the layer until full-trainer integration, broader gradient and duplicate-prevention cases, and the target hardware checks pass. Conservative culling can increase work.

This layer currently covers the ordinary RGB splat forward/backward paths. The separate 3DGUT meshing/moments path still uses the AABB center for ellipse culling in its tile intersector and rasterizer, so mesh seam correctness is not established by this layer or the RGB fixture.
