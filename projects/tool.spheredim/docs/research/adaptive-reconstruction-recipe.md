# Adaptive reconstruction recipe

The 2026-11-16 trial takes selected timestamps from `adaptive-frame-final-20261116/final-window-2.json` (`selected_indices`) and unions them with the original 18 paired evaluation timestamps from `rig-dense-splat-6000-20261115/prepared/manifest.json` (`heldout_evaluation_order`). The union contains 290 timestamps. All 18 original timestamps are excluded from splat training even when the selector chose them. Both lens images stay together. These views contributed to SfM, so the evaluation is held out from splat training, not from camera estimation.

For SfM, filter the existing 1024-pixel dense dataset manifest to this union. Hardlink each selected `images`, `masks`, and `feature-masks` file, retaining the `cam0` and `cam1` directories. Hardlink `rig-metadata.json`. Filter `rotation-priors.csv` by exact image name and write LF line endings; the pinned parser requires an exact LF-only header. Filter `rig-density-pairs-20261115/dense.tsv` to pairs whose two names are in the union, and check that every image belongs to one connected component. The trial graph has 580 nodes and 23,696 edges. No images are resampled and no virtual views are made.

The exact SfM command, selection hash, source manifest hash, prior hash, held-out frame list, and limits are recorded in the trial's `adaptive-1024-sfm-20261116/manifest.json` beside the recording. The command uses the retained explicit-pairs SfM binary, physical rig, original priors, 1024 ERP camera model, and filtered graph. Its workspace is limited to 200 MiB; the watchdog also enforces the 15 GB task limit, 2 GB support limit, 35 GiB free reserve, and 900-second timeout. The first attempt stopped because its generated prior header used CRLF. Its log and status are retained; the corrected attempt reused its workspace. Its elapsed time therefore includes reuse of the first attempt's work and is not a clean runtime comparison.

For splat training, create a second filtered manifest and hardlink selected `images` and `masks` from `rig-dense-splat-6000-20261115/source`. This retains the previously reviewed mask overrides, including the evaluation mask for frame 2040. Prepare with `prepare_splat.py`, passing `--eval-frames-json` with the frozen 18-frame JSON, `--iterations 6000`, and `--save-every 6000`. The trial keeps a full final checkpoint and saves no intermediate checkpoints. Validate the generated manifest with `run_splat.verify`, then append the 6k baseline's `--refine-stop-iter 0 --refine-stop-num-iter 2000`. The exact validated command, output limit and prelaunch accounting are recorded in `splat-plan.json`; `splat-status.json`, `splat.log`, and `splat-result.json` record execution. The trainer monitor checks camera count, completion, final PLY, output size, timeout and free reserve; a concurrent inventory watchdog enforces the task and support limits.

Compare the same 36 saved held-out source images and common masks using `compare_splat_pixels.py`, with the 6k anchor and 7k incumbent as separate baselines. Report pooled spherical-weighted squared error, raw pixel error, and visible detail separately. A lower error alone does not establish recovered detail.

## Fixed-pose selection control

The selection-only control uses the same 290-timestamp filtered splat source and the same 18 paired heldouts, but `--allow-model-superset` selects those paired camera poses from the original dense 1024 SfM model while retaining its complete original point cloud. This option validates every image name and physical lens pair before filtering. The prepared seed SHA-256 and all original model hashes were verified identical to dense 6k; all 36 heldout source and mask hashes were also verified. The identical seed was then hardlinked to the baseline seed. This control uses the same 6,000 updates and refinement settings, but passes `--compact-final-checkpoint --save-every 6000`; its final checkpoint lacks optimizer state. The exact command, budget and status are recorded under `adaptive-fixed-poses-6000-20261116` beside the recording. Compare its 36 heldouts against both dense 6k and adaptive fresh-SfM 6k. The control separates the effect of selected observations from using a newly estimated model; it does not establish trajectory ground truth.
