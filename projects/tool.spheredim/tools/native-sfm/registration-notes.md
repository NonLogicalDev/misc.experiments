# Fixed-rig registration prototype

`recover_landmark_descriptors.recover(model_dir, workspace_dir, image_names)` reconstructs the original feature row for each compacted model row from the retained VKMT match graph. It verifies every selected image's feature coordinates and each linked point's reciprocal track. It returns descriptors and 3D points in memory. It expects VKMT version 5, VKFT version 6, and 128-byte SIFT descriptors. Use the exact original workspace and model: unrelated matches or recomputed features can invalidate the compaction map. Do not join descriptors by x/y because multiple orientations can share coordinates.

`rig_pose.fit_rig_pose` fits one world-to-rig pose with fixed per-lens extrinsics against spherical bearings and fixed landmarks. It is a local optimizer: it needs a nearby initialization and can converge to an incorrect pose. `validate_fixed_rig` checks the nonzero calibration against existing paired poses; `validate_registration` exposes experimental evidence gates for distinct landmarks, both lenses, image-region spread and source timestamps. These gates do not establish physical coverage or independent accuracy. The caller must reject a failed fit and retain the original anchor, record exact thresholds and input hashes, and preserve the original model and seed. Per-lens images must be synchronized physical observations; generate bearings in the basis used by `compare_rigs.ray` and use the actual fixed camera-from-rig extrinsics.

Run focused checks from `tools/native-sfm` using the existing offline environment:

```sh
uv run --offline --isolated --no-project --python 3.14 --with-requirements ../../vendor/360DVO/requirements-macos-arm64-py314.lock python -B -m unittest -v test_recover_landmark_descriptors test_rig_pose
```

Native feature extraction uses `spirula-sfm extract IMAGES -o FEATURES --features sift --max-features 4096 --max-image-size 1024 --exif-orientation none --masks MASKS --feature-masks FEATURE_MASKS`. Use the directory form to intersect both masks and check the binary hash, source image hashes, mask hashes and pixel-coordinate configuration. Run GPU extraction only in an authorized GPU window. Propagated operator masks are not independently reviewed. A native 1024 export differs from an area-reduced 2048 export, so evaluate that difference rather than assuming pixel identity.

`register_rig_frames.py` is the reusable pilot command. Supply `--model` for the original COLMAP directory, `--workspace` for its VKMT/features, `--selection` for a JSON object with `frames` rows containing `frame`, `anchor`, and `timestamp_microseconds`, `--new-features` for the new `cam0/` and `cam1/` VKFT directories, `--feature-manifest` for extraction provenance, `--input-manifest` for the prepared observations, `--anchor-manifest` for the original dataset, `--seed` for the original seed, and `--output` for a new report. The feature provenance must contain `input_manifest_sha256` and `features` hashes keyed as `features/cam0/frame_NNNNNN.bin` and `features/cam1/frame_NNNNNN.bin`. The prepared manifest uses `source_frame` and `timestamp_microseconds` in each row. All inputs must describe the same physical capture.

Matching compares the best descriptor from each distinct landmark, so duplicate orientations or observations of one landmark do not become the second-best competitor. The command selects five nearest original timestamp pairs for landmark descriptors, excluding the query frame itself, and reports which frames it used. It checks original model and seed hashes again after fitting and never changes them. A failed gate records no candidate pose and instructs the caller to keep the original anchor. Condition and linearized parameter standard deviations measure local fit geometry; they are not calibrated uncertainty or a ground-truth accuracy claim.
